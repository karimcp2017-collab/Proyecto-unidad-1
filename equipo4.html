Escítala Espartana

Antecedentes

La Escítala Espartana es uno de los métodos de cifrado más antiguos conocidos. Fue utilizada en la antigua Esparta, principalmente por los militares, para enviar mensajes de manera que no pudieran ser comprendidos fácilmente si eran interceptados.

El método utilizaba una vara o cilindro alrededor del cual se enrollaba una tira de material. El mensaje se escribía sobre la tira siguiendo las líneas formadas por la vara. Al desenrollarla, las letras quedaban desordenadas y el mensaje no podía leerse directamente.

¿Cómo funciona?

La Escítala es un método de transposición. A diferencia de otros métodos de cifrado, no cambia las letras del mensaje, sino que cambia el orden en el que aparecen.

En nuestro programa, la vara se representa mediante una matriz. La clave indica el número de columnas que tendrá la matriz.

El proceso de cifrado se realiza de la siguiente manera:

1. Se introduce el mensaje original.
2. Se establece el número de columnas mediante la clave.
3. El mensaje se escribe en la matriz por filas.
4. La matriz se lee por columnas para obtener el mensaje cifrado.

Para descifrar se realiza el proceso inverso: el mensaje cifrado se coloca por columnas y después se lee por filas para recuperar el mensaje original.

Ejemplo

Si tenemos el mensaje:

HOLA

y utilizamos una clave de 2 columnas, la matriz queda:

H | O
L | A

Al leer las columnas obtenemos:

H → L → O → A

Por lo tanto, el mensaje cifrado es:

HLOA

Proceso de descifrado

Para descifrar HLOA con una clave de 2 columnas, primero se coloca el texto cifrado por columnas:

H | O
L | A

Después se lee la matriz por filas:

H → O → L → A

Obteniendo nuevamente el mensaje original:

HOLA
